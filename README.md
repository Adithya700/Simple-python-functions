# Simple-programs using python-functions

A collection of simple menu-driven Python programs for managing employee and student records using basic Python concepts such as functions, lists, dictionaries, file handling, and JSON operations.

## Project Overview

This repository contains three separate console-based applications:

1. Employee Payroll Management System
2. Student Record Management System (Text File Storage)
3. Student Record Management System (JSON File Storage)

These programs demonstrate CRUD (Create, Read, Update, Delete) operations and data persistence using files and JSON.

---

## Features

### 1. Employee Payroll Management System

A menu-driven application for managing employee information and payroll details.

#### Menu Options

1. Add an employee
2. View employees
3. Search employee
4. Update employee details
5. Delete employee
6. Save data to JSON file
7. Calculate gross salary
8. Display department-wise employee list
9. Find highest-paid employee
10. Display total employees, average salary, lowest salary, and highest salary

#### Additional Functionalities

* Employee data storage using dictionaries and lists
* Salary calculations and payroll statistics
* Department-wise employee categorization
* JSON file handling for persistent storage

## How to Run

Clone the repository:

git clone https://github.com/Adithya700/Simple-python-functions.git


Navigate to the project directory:
cd Simple-python-functions


Run any program:
Employee Management:
python Employee_Management/employee_manage.py
Student Management (Text File):
python Student_Management(file)/student_recordfile.py
Student Management (JSON File):
python Student_Management(json)/student_recordjson.py
